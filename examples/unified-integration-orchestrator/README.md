## 🚀 Quick Start

### Installation
```python
from examples.unified_integration_orchestrator.iraqi_ai_ecosystem_orchestrator import (
    IraqiAIEcosystemOrchestrator,
    IraqiWorkflowContext,
    ProfessionalDomain
)

# Initialize the complete Iraqi AI ecosystem
orchestrator = IraqiAIEcosystemOrchestrator()
```

### Basic Usage
```python
import asyncio

async def main():
    # Initialize ecosystem
    orchestrator = IraqiAIEcosystemOrchestrator()
    results = await orchestrator.initialize_ecosystem()
    
    # Execute Iraqi legal workflow
    legal_context = IraqiWorkflowContext(
        professional_domain=ProfessionalDomain.LEGAL,
        user_id="iraqi_lawyer_001",
        cultural_requirements={
            "islamic_compliance": True,
            "family_sensitivity": True
        },
        language_preferences=["arabic", "english"],
        islamic_compliance_required=True
    )
    
    legal_results = await orchestrator.execute_iraqi_workflow(legal_context)
    print(f"Legal workflow success: {legal_results['success']}")

asyncio.run(main())
```
